One emoji for my dream vacation: a desert island, 🏝️ — white sand, clear water, and nobody asking me for anything.

`main.ts` writes that exact emoji to `/output/entry.txt` (7 bytes UTF-8, no trailing newline). Run with `MAKEFUN_OUTPUT_DIR` set, or it defaults to `/output`.
